# UAS7（荨麻疹活动评分）

[条件、来源与许可](https://elucenia.org/zh/tools/uas7)

## 使用方法

在门户中使用工具，或通过本地 HTTP 服务器打开 index.html。选择语言，填写各字段，然后计算。

### 第 1 天 · 24 h 内的风团（丘疹）

`d1p`

- `0` — 无
- `1` — \< 20
- `2` — 20 至 50
- `3` — 24小时内\>50个风团，或有大片融合的风团区域

`d1c`

- `2` — 中度（令人困扰，但不影响正常日常活动或睡眠）
- `3` — 重度（严重瘙痒，造成的困扰足以影响正常日常活动或睡眠）

## 方法版本

UAS7/Młynek 2008：7日UAS 0–6、总0–42；EAACI/GA²LEN/EuroGuiDerm/APAAACI 2022阈值

## 已记录的公式

患者每日（24h）记录：

风团: 0 = 无; 1 = \< 20; 2 = 20–50; 3 = \> 50 (或大片融合区).

瘙痒: 0无；1轻（存在，不困扰）；2中（困扰但不影响活动/睡眠）；3重（影响活动/睡眠）。

每日UAS = 0–6. UAS7 = 连续7天之和 (0–42).

## 限制与适用人群

UAS通过连续数日记录风团数量与瘙痒程度监测慢性荨麻疹活动度。它不代表血管性水肿等全部表现，也不能代替生活质量评估。UAS7及后续类别须遵循各自时间定义和来源。

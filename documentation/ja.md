# UAS7（蕁麻疹活動性スコア）

[条件・出典・許諾](https://elucenia.org/ja/tools/uas7)

## 使い方

ポータルでツールを使用するか、ローカルHTTPサーバー経由でindex.htmlを開いてください。言語を選択し、項目を入力して計算してください。

## 入力項目と単位

### 1日目 · 24 h の膨疹（丘疹）

`d1p`

- `0` — なし
- `1` — \< 20
- `2` — 20 ～ 50
- `3` — 24時間で50個を超える膨疹、または広範囲に融合した膨疹

### 1日目 · そう痒

`d1c`

- `0` — なし
- `1` — 軽度（存在するが、不快さや煩わしさを伴わない）
- `2` — 中等度（煩わしいが、通常の日常活動や睡眠には支障をきたさない）
- `3` — 高度（強いそう痒があり、その煩わしさが通常の日常活動や睡眠に支障をきたす）

## 方法の版

UAS7/Młynek 2008：7日UAS 0～6、合計0～42、EAACI/GA²LEN/EuroGuiDerm/APAAACI 2022閾値

## 記載された計算式

毎日（24h）患者が記録：

膨疹: 0 = なし; 1 = \< 20; 2 = 20–50; 3 = \> 50 (または広い融合範囲).

かゆみ: 0なし、1軽度（存在するが気にならない）、2中等度（気になるが活動・睡眠を妨げない）、3重度（活動・睡眠を妨げる）。

日次UAS = 0–6. UAS7 = 連続7日合計 (0–42).

## 限界・対象集団

UASは、数日にわたって記録した膨疹の数とかゆみにより、慢性蕁麻疹の活動性を監視します。血管性浮腫など全ての症状を表すものではなく、生活の質の評価に代わるものでもありません。UAS7と後のカテゴリーは、それぞれの時間的定義と出典に従う必要があります。
